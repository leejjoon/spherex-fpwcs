spherex-fpwcs

Check and repair the astrometry of SPHEREx Level-2 spectral images without fitting stars. The tool reads the headers of the six detectors of one exposure, fits one telescope attitude to them, and regenerates the WCS of any detector that disagrees.

Under the DR1 header the circles drift off the stars towards the left edge of the detector, by up to 11 pixels, although the file is flagged FINAST = 0. Under the WCS regenerated by spherex-fpwcs they sit on the stars everywhere. Switch the WCS or press Blink to compare; the original report used K < 10.5, which the slider reproduces.

Six detectors, one attitude

All six detectors are exposed together and do not move relative to each other, so one telescope attitude and one plate scale fix the WCS of all of them. Each map shows how far a detector's DR1 header departs from that common solution. A bad header stands out against the five that agree, and those five are enough to regenerate it.

Use it

pip install git+https://github.com/leejjoon/spherex-fpwcs

spherex-fpwcs check  level2_2026W13_2A_0568_2D5_spx_l2b-v27-2026-237.fits   # diagnose
spherex-fpwcs header level2_2026W13_2A_0568_2D5_spx_l2b-v27-2026-237.fits   # print the new WCS cards
spherex-fpwcs apply  level2_2026W13_2A_0568_2D5_spx_l2b-v27-2026-237.fits -o fixed.fits

The headers of the other five detectors are fetched from the public SPHEREx bucket with byte-range requests; a run takes about five seconds. The package depends only on numpy and astropy. See the user guide for options and Python use, how it works for the algorithm, and the report for the SPHEREx distortion, its stability over 13 months and the full validation.

Limits: at least three detectors of the exposure must be available and most of them sound. The focal-plane template is the median of DR1 (processing v27) solutions, so it inherits any error common to all of them.
